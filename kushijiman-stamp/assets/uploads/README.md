# 串じまん・炙り家しんいち 画像アップロード置き場

ここに、完成したイラスト・ロゴの PNG 画像をアップロードしてください。

## 推奨ファイル名（半角英数字）
- `logo-kushijiman.png` : 串じまんロゴ（透過）
- `logo-shinichi.png` : 炙り家しんいちロゴ（透過）
- `chicken-beer.png` : ビールで乾杯するニワトリ
- `chicken-sake.png` : 一升瓶を持つニワトリ
- `chicken-yakitori.png` : 焼き鳥を持つニワトリ
- `chicken-tshirt.png` : Tシャツ姿のニワトリ
- `chicken-hoodie.png` : パーカー姿のニワトリ
- `chicken-thumbs-up.png` : グッドサインのニワトリ
- `reward-tshirt.png` : 手書きTシャツの切り抜き
- `reward-hoodie.png` : 手書きパーカーの切り抜き

GitHub 画面でこのフォルダを開き、`Add file` → `Upload files` を選択。画像をまとめてドラッグ＆ドロップして `Commit changes`。

**注意:** GitHubにアップロードしただけではアプリには自動反映されません。画像ファイル名を確認してHTML側の参照を差し替えます。公開リポジトリなので個人情報や秘密鍵は絶対に置かないでください。
